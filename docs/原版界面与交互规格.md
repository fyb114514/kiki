# kiki 原版界面与交互规格

> 依据:用户提供的 3 张原视频截图 + 用户口述
> 目标:**完全相同**。本文件是唯一依据,改 UI 前先读它。

---

## 一、屏幕结构(自上而下)

```
┌─────────────────────────────┐
│ 系统状态栏                   │
├─────────────────────────────┤
│                             │
│   斑马纹对话区(占满)         │  ← 交替色横带 + 对话文字
│                             │
│   ← 横带铺满整个区域,       │
│     文字直接压在带上         │
│                             │
├─────────────────────────────┤
│  底部:半透明灰 + 立绘        │  ← 红色移动条在这里
└─────────────────────────────┘
```

**关键认知**:原版**不是"每条消息一个气泡"**,而是
**整个对话区铺满交替色横带**,对话文字直接叠在带上。

---

## 二、斑马纹(核心视觉)

| 项 | 规格 |
|---|---|
| 形态 | **满宽横带**,固定高度,上下排列铺满整个对话区 |
| 颜色 | 两种交替:浅蓝白 / 中蓝(截图实测约 `RGB(160,176,192)` 与 `RGB(16,64,144)` 一带) |
| 带高 | 截图约 40~55px(按 818px 高的照片折算,实机约 **44~48dp**) |
| 文字 | 直接压在带上,**没有独立的文字底色** |
| 文字色 | 深色(`#1A1A1A` 左右),在浅带上;深带上的字需更亮 |

> ⚠️ 截图是**翻拍屏幕的照片**(有摩尔纹与透视),颜色有偏色。
> 上面数值只能当起点,**最终以用户实机对比为准**。

---

## 三、对话排版

| 项 | 规格 |
|---|---|
| **用户的话** | **右对齐** |
| **她的话** | **左对齐** |
| 长文本 | 换行后**仍是同一条**(不切成多条),可能跨多条横带 |
| 行高 | 与横带高度对齐(文字基线落在带内) |
| 顺序 | 自上而下,最新的在下面,自动滚到底 |

截图里的例子(可作回归样例):

```
我不知道，他是谁                      ← 左(她)
                        微软公司CEO    ← 右(用户)
是微软公司出名吗？                     ← 左(她)
                                没错   ← 右(用户)
明白了                                ← 左(她)
                        比尔盖茨很出名 ← 右(用户)
因为他是微软公司CEO                    ← 左(她)
```

## 四、底部区域

| 元素 | 规格 |
|---|---|
| 底色 | **半透明灰**(能透出背景) |
| 左侧 | 一个**红色块** |
| 右侧 | 一个**竖向深红条** |
| 立绘 | 底部区域中央有角色立绘(截图可见) |

## 五、红色移动条(用户明确描述)

> 「打开时底部灰色半透明图形上会有一个**左右移动的红色条**,
>  还有类似**渐变拖尾**的效果,而且这个效果**除了用户说话时都在**。」

| 项 | 规格 |
|---|---|
| 位置 | 底部灰色区域内 |
| 运动 | 左右往复移动 |
| 效果 | 带**渐变拖尾**(尾巴渐隐) |
| **何时显示** | **只要用户没在说话就一直显示** |
| **何时消失** | 用户说话时 |

**语义**:红色条 = "我在听" 的指示器。

## 六、交互流程(★ 最重要)

> 「他是**自己说完几句话就会开始识别**,
>  **不需要用户动手点击或长按**。」

**原版是全程自动的多轮对话,没有任何按钮。**

```
    ┌──────────────────────────┐
    │  她说话(TTS 播放)         │  红色条隐藏
    └───────────┬──────────────┘
                ↓ 她说完
    ┌──────────────────────────┐
    │  自动开始录音              │  红色条显示,左右移动
    └───────────┬──────────────┘
                ↓ 检测到用户说完(静音)
    ┌──────────────────────────┐
    │  识别 -> 思考 -> 回答      │  红色条隐藏
    └───────────┬──────────────┘
                ↓
         回到"她说话",循环
```

### 与当前实现的差异(必须改)

| 项 | 现在的实现 | 原版 |
|---|---|---|
| 开始说话 | **长按/点击**底部区域 | **自动** |
| 结束说话 | 松手 / 再点一下 | **静音自动判断** |
| 底部提示文字 | 有("长按说话 / 点一下开始") | **无** |
| 红色移动条 | 无 | **有,常驻** |
| 说话区变色 | 变绿表示录音 | 未观察到 |

**结论:当前的手动交互要整体替换为自动循环。**

```
她(左): 明白了
你(右): 比尔盖茨很出名

```
