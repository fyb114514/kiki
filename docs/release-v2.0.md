# kiki v2.0 — 四项能力全部实现

> **v1.0 仍然保留**，可在 [Releases](https://github.com/fyb114514/kiki/releases) 里继续下载。
> v1.0 是早期版本（429 MB，内置 Qwen2.5-0.5B 语言模型）；
> v2.0 删掉了语言模型，改用规则引擎 + 事实图，并把语音引擎换成了 Paraformer。

---

## 这一版最大的变化

### 1. 语音识别：Vosk → Paraformer

同一句 **"水在一百摄氏度沸腾"**，用真机录音对比：

| 引擎 | 识别结果 |
|---|---|
| Vosk small（v1.0，42 MB） | `水灾 一百 舒适度 都 沸腾` ❌ 错 4 处 |
| **Paraformer（v2.0，213 MB）** | **`水在一百摄氏度沸腾`** ✅ |

用的是**中英双语 zh-en 模型**，所以中英文混说也能认。

另外调了识别的"听觉"：

| 参数 | 旧 | 新 | 原因 |
|---|---|---|---|
| 静音判停 | 2800 ms | **1000 ms** | 旧值太长，必须等环境彻底安静才收尾 |
| 音量门限 | 固定 450 | **自适应 max(620, 底噪×2.6)** | 旧的把环境噪音当成说话，一路录满 20 秒 |

### 2. 四项能力全部实现

对照 2011 年原版视频里说明卡列出的能力清单：

| 原版能力 | 状态 |
|---|---|
| 逻辑推理 + 主动记忆 | ✅ 与原版视频**逐句一致** |
| 多音字分辨 | ✅ Paraformer |
| 中英文混合分辨 | ✅ 双语模型 |
| **语言总结** | ✅ 新增 —— `基础的基，朋友的友` → `基友` |
| 上下文理解 | ✅ |
| **网络学习 + 用户偏好 + 新知识覆盖** | ✅ 新增 |

**语言总结**不是生成式摘要，而是可解释的结构化提取：
从"X的A，Y的B"取字拼接成 AB，且**结果必须命中 4 万词表**才输出 ——
拼不出真词就返回空，宁可不总结也不编（防止 `电脑的电，桌子的桌` → `电桌`）。

**新知识覆盖旧知识**靠给事实加**来源优先级 + 时间戳**：

```
用户亲口教的  100  ← 最高
用户纠正的     80
联网学到的     50
内置知识       30
推理推导的     10
```

同一个（主语,关系）下优先级高者胜、同级则新者胜。
**关键规则：联网知识不会覆盖用户亲口教的东西。**

## 修复的问题

### 「我都说了不是了他还记着」

原实现里用户说"不是"时**只回一句话，什么都没删**。现在补齐了完整删除链
（内存事实图 + `bySubject`/`byObject` 两个索引 + 本地数据库）。

修的过程中发现一个**更深的 bug**：删除时用的实参是错的 ——

```java
learnedWho = answer;      // "某公司老板"   ← 存的是原文
...
learnedWho = keyEntity;   // "某公司"       ← 随后被覆盖成抽取后的实体
```

于是删除时拿 `"某公司"` 去匹配 `"某公司老板"`，**永远删不中**。
新增 `learnedIdentity` 保存身份原文后解决。

### 「我没说话它自己就输出」

根因是我为观察红条动画加的一个**临时 UI 测试模式**忘了删 ——
它每隔 3 秒自动切换"她说话/她在听"状态。**已彻底移除。**

### 联网查不到时不再追问

改成直接说 **"我查不到「X」，你教教我好不好？"**，把主动权交回用户。
（与她"当场不懂就反问"的主动学习闭环不冲突：那是没去查的情况，这是查过确实没有。）

### 语气词不再被当成实体

说"嗯"、"好的"、"就是"不再触发联网学习和因果追问。

## 界面

恢复到**每条消息自带条纹背景**的做法（她的话浅底深字、你的话深底白字，都半透明，
所以背景插画会透出来）。

> 我试过三次"整屏画条纹"，都因**消息高度是可变的**（1 行 / 3 行）而失败 ——
> 要么文字偏移，要么行与行重叠。让每行自带条纹最稳。
> 这段踩坑记录写在 `MessagesLayout.java` 的注释里。

## 安装

| 要求 | 值 |
|---|---|
| **CPU 架构** | **仅 arm64-v8a** |
| **系统版本** | Android 7.0+（API 24） |
| **内存** | 建议 4 GB+ |
| **可用存储** | 约 450 MB（APK 225.7 MB + 首次启动释放模型 213 MB） |
| **麦克风** | 必须授权 |

**首次启动会释放 213 MB 模型到应用私有目录**（约 0.4 秒，因为 asset 是压缩存放的，
ONNX Runtime 需要能内存映射的文件）。

> 换模型时靠 `assets/asr/model.id`（模型内容指纹）判断是否需要重新释放 ——
> 只检查"文件是否存在"会导致新模型永远释放不出来（这一版实际踩过）。

## 已知限制

- 只支持 arm64
- **中文维基在中国大陆通常不可达**，联网学习实际主要靠百度百科兜底
- 立绘：原版底部有 Q 版立绘，本复现**没有**（从原版视频抠图失败，
  因为原版条纹本身在滚动，底色差法与时间方差法都失效）
- 内置知识库 1795 条事实，覆盖面有限 —— 但她会**问你**，所以能自己长
