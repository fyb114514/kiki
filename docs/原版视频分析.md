### 换模型时踩的坑（已修，值得记住）

`ModelInstaller` 原来只判断"模型文件在不在"。把单语模型换成双语模型时
**文件名没变**，旧模型一直躺在私有目录里被复用 ——
表现是"代码改了、APK 也换了，识别行为却完全没变"。

修法：assets 里增加 `model.id`（模型内容算出的指纹），
释放时一并写入 `.model.id`，启动时比对；不一致就删掉旧的重新释放。
实测日志：

```
模型已更新(null -> paraformer-bilingual-zh-en/6b1d97388ed6b0ac)，重新释放
已删除旧模型文件 model.int8.onnx / tokens.txt
释放模型文件: model.int8.onnx -> 213 MB
指纹已写入: paraformer-bilingual-zh-en/6b1d97388ed6b0ac
```
