# 怎么导出「撮」的关注列表

> ⚠️ **注意:下面这段代码不是用来双击运行的!**
> 如果你双击 .js 文件,Windows 会用「脚本宿主」去跑它,必然报「语法错误」——
> 因为那是浏览器专用的新语法,不是给 Windows 跑的。
>
> **正确做法:复制代码 → 粘贴到浏览器的「控制台」里 → 回车。** 见下面步骤。

---

## 操作步骤(约 30 秒)

**第 1 步** —— 用**你自己的 B 站账号**登录(接口需要登录态,没登录会报 `code=-101`)

**第 2 步** —— 打开这个页面:

```
https://space.bilibili.com/324548/relation/follow
```

**第 3 步** —— 按键盘 **F12** 打开开发者工具

**第 4 步** —— 点击顶部的 **「控制台」** 标签(Console / コンソール)

> 如果控制台里提示"请勿粘贴"之类,先手动输入 `allow pasting` 然后回车,再继续。

**第 5 步** —— 复制下面**整段代码**,粘贴到控制台最下方的输入行,按**回车**

```javascript
(async function () {
  var MID = 324548, out = [], page = 1, total = 0;
  console.log('开始抓取…');
  while (true) {
    var url = 'https://api.bilibili.com/x/relation/followings'
            + '?vmid=' + MID + '&pn=' + page + '&ps=50&order=desc&order_type=attention';
    var j;
    try {
      var r = await fetch(url, { credentials: 'include' });
      j = await r.json();
    } catch (e) { console.error('请求失败', e); break; }
    if (j.code !== 0) {
      console.error('接口错误 code=' + j.code + ' ' + j.message);
      if (j.code === -101) console.error('→ 没登录,请先登录 B 站再试');
      break;
    }
    var list = (j.data && j.data.list) || [];
    total = j.data.total || 0;
    if (list.length === 0) break;
    for (var i = 0; i < list.length; i++) {
      var u = list[i];
      var sign = (u.sign || '').replace(/\s+/g, ' ').trim();
      out.push('[' + out.length + 1 + '] ' + u.uname + ' (mid=' + u.mid + ')' + (sign ? ' | ' + sign : ''));
    }
    console.log('  已抓 ' + out.length + ' / ' + total);
    if (out.length >= total) break;
    page++;
    await new Promise(function (s) { setTimeout(s, 700); });
  }
  var text = out.join('\n');
  console.log('=== 完成,共 ' + out.length + ' 人 ===');
  console.log(text);
  try {
    await navigator.clipboard.writeText(text);
    console.log('✅ 已复制到剪贴板,直接粘贴发给我');
  } catch (e) {
    console.log('⚠️ 自动复制失败,请手动选中上面的内容复制');
  }
})();
```

**第 6 步** —— 等它跑完(约 4 页,5 秒),看到 `✅ 已复制到剪贴板`,把内容粘给我

## 我要这份列表干什么

我会从 190 人里筛出**可能是 2011 年那个 kiki 项目作者**的人:

- 签名含 `开发 / 程序员 / Android / 独立开发 / AI / 算法 / 前端 / 后端` 等技术词
- 名字看起来是技术向的
- 投稿内容是技术类(而非 ACG 类)

然后给你一份**短名单**,你再决定私信谁。

> 背景:「撮」本人是二次元爱好者(关注一半是声优/VTuber),自己发的也是 ACG 内容,
> 所以他大概率只是搬运动漫内容时顺手搬了这条 kiki 视频。
> 但如果他 190 个关注里**藏着做技术的人**,那个人就可能认识作者。
