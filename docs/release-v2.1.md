# kiki v2.1 — 修复推理与记忆问题

> **v1.0 / v2.0 仍然保留**，可在 [Releases](https://github.com/fyb114514/kiki/releases) 里下载。
> v2.1 修的是 v2.0 的四个 bug —— 都来自实际使用截图。

---

## 修了什么

### 1. 推理荒诞：「是康神是一条狗让康神出名吗？」

**现象**：你教她"康神是一条狗"，她追问
`是康神是一条狗让康神出名吗？` —— 整句话被当成了一个实体。

**根因**：回答被**整句**当成身份存下来：

```
康神 | 是 | 康神是一条狗        ← 错
```

**修法**：新增 `KikiDialog.extractPredicate()`，先把身份抽出来再存：

| 你说的 | 存下来的身份 | 追问句 |
|---|---|---|
| 康神是一条狗 | `一条狗` | 是**一条狗**让康神出名吗？ |
| 他是微软公司CEO | `微软公司CEO` | 是**微软公司CEO**让…吗？ |
| 一只猫 | `一只猫` | 是**一只猫**让…吗？ |

### 2. 否定删不干净：「说了不是她还记着」

**现象**：你说"不是"，她答"好的，我忘掉这个"，但**随后照样用那条知识回答**。

**根因**：`Brain.addFact` 会对主语/宾语做**规范化**（全角转半角、去空格等）后再入库，
而删除时用的是**原始串** —— 键对不上，`removeFact` 找不到要删的行。

**修法**：删除时**同时按规范化键和原始串**删，内存事实图与本地数据库都清。

### 3. 【最严重】退出就忘

**现象**：关掉 App 再打开，之前教她的全都不记得了。

**根因**：`persistLearned()` 一直在往数据库写，但**启动时从来没有读回来** ——
`Store.loadFacts()` 定义了却**从未被调用**（只在自检里用过）。
于是重启后内存事实图是空的，所有自学知识全丢。

**修法**：新增 `KikiBrain.restoreFacts()`，在 `initBrain()` 里调用。
真机实测：

```
启动时恢复自学事实 269 条
```

（也就是说库里其实积了 269 条，但之前从没被用过。）

### 4. 联网学到的知识不进内存图

**现象**：联网"学完"了，但紧接着问同一个词还是答不出。

**根因**：`NetworkLearner` 直接写数据库，内存事实图不知道这件事。

**修法**：联网成功后调用 `brain.reloadFacts()` 同步。

## 顺带修的两个

**覆盖规则的边界 bug**：同一毫秒内的两次写入 `updated_at` 完全相等，
原来用 `updated_at < now` 删不掉旧行；而新旧**宾语不同**时
`INSERT OR REPLACE` 也替换不掉（主键含宾语）→ 新旧并存，查询返回旧的。

改成 `<=` 之后又踩了一个新坑：**会把自己删掉**（自己刚插入，时间戳正好等于 now），
自检立刻从 11/12 掉到 6/12。最终加上 `o <> 本条` 才对。

**自检污染正式库**：`Feature2SelfTest` 会把测试事实真的写进正式数据库，
跑一次留一条垃圾，残留数据还会干扰下一轮自检（优先级 100 的老数据把新的压住，
导致前几条断言假失败）。现在自检结束会清理自己。
