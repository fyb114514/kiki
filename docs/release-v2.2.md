# kiki v2.2 — 新增「清除数据」指令，修掉会污染知识库的严重 bug

> **v1.0 / v2.0 / v2.1 都保留**，可在 [Releases](https://github.com/fyb114514/kiki/releases) 下载。

---

## 新增：`system清除数据` 指令

说完这一句，**她忘掉你教过的一切**，回到出厂状态。

```
你：system 清除数据
她：好的，我把之前学的都忘掉了。现在只记得出厂的知识。
```

**实测数据**：

```
教完之后自学事实 = 4 条
清除用户数据完成,原有自学事实 4 条
清除后自学事实 = 0 条        ← 用户数据清空
清除后事实图 = 1795 条       ← 内置知识一条没丢
[OK] 能答内置问题
[OK] 清完还能重新学新知识
```

**清什么**：你教的事实、问答对、说话偏好、话题统计、半截对话存档
**不清什么**：内置的 1795 条出厂知识 —— 这不是"格式化 App"，是"忘掉你教的东西"

**识别很宽松**（语音识别常弄乱空格大小写）：

| 说法 | 结果 |
|---|---|
| `system清除数据` | ✅ |
| `system 清除数据` | ✅ |
| `system，清除数据。` | ✅ |
| `SYSTEM清除数据` | ✅ |
| `system　清除数据`（全角空格） | ✅ |
| `为什么清除数据` | ❌ 不误判 |
| `清除数据`（没有 system） | ❌ 不误判 |

> 为什么要 `system` 前缀：中文口语里"清除数据"太容易误触发。

## 修掉一个**会慢慢毁掉知识库**的严重 bug

**现象**（来自实际使用截图）：她反问"微软公司是谁？"，你只答了一个字"**微**"，她就把
`微软公司 | 是 | 微` 当成事实存了下来。之后所有回答都乱：

```
你：康氏是谁
她：康氏是谁是微软公司的一种。我记性很好的。      ← 荒谬
```

**根因**：落盘前的质量闸**没有下限**，只拦超长、不拦超短。

**修法**（两条同时加）：
- 宾语也要求 ≥ 2 字（单字没有信息量）
- 状态机侧：抽不出合格身份就直接说 **"这个我没听清，你再说一遍好不好？"**，**什么都不写**

**修复后**：

```
说: 微  -> 这个我没听清，你再说一遍好不好？
库内容: 康神|是|一条狗     ← 干干净净
```

顺带修了：连问两次"康氏是谁"时，第二句会被当成第一句的答案消费掉。现在不会了。

---

## 顺带修的两个

**网络查询不再刷屏**：之前查"康氏是谁"会把整段维基正文（几百字）当回答吐出来，
屏幕刷满、语音念半天。现在截断到 60 字。

**用户偏好画像更准**：之前"好的""嗯"这种应答词也被算成"提问"，
把"爱问为什么"淹没了（画像显示"爱提问"，而用户其实一直在追问原因）。
现在应答词单独归一类。

---

## 一个新的认识：主语要严格，宾语要宽松

这轮踩了个有意思的坑：我给质量闸加"单字不成实体"之后，
特性 2 自检从 12/12 掉到 **11/12** —— 因为**有些正当事实的宾语就是单字**。

所以规则定为：

| 位置 | 要求 | 理由 |
|---|---|---|
| **主语** | 必须像实体（≥2 字、无疑问词、无标点） | 主语是查询的键，脏了会污染全库 |
| **宾语** | 只要求 ≥2 字、不太长 | 宾语可以很灵活，卡太死会误伤正当事实 |

## ⚠️ 升级后建议做一次清理

v2.2 之前的知识库里可能已经混进了被污染的数据
（例如 `微软公司 | 是 | 微` 这种，v2.1 及更早的版本拦不住）。

装上 v2.2 后，**对她说一句 `system清除数据`**，就干净了。
